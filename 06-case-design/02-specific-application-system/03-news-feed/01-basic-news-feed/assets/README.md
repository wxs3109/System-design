# News Feed Basic Layout Diagram Resources

This directory saves the editable Draw.io architecture diagram of the basic version.

## Visual convention

- Blue: Client request and News Feed API;
- Green: Post and Follow data;
- Solid arrow: synchronous request or data reading and writing.

It is recommended to use VS Code’s Draw.io Integration extension or [draw.io](https://app.diagrams.net/) to open the source file.
