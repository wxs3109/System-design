# System Design 学习能力矩阵

> 状态：覆盖规划，非实现承诺。更新于 2026-09-20；共享仿真盘点基于 `6033e47`，后续增加独立算法、故障恢复、并发、复制与共识等基础 Lab。除明确标为“已上线”的 18 题外，本文练习均为候选；已上线表示当前代码具备可运行入口。

## 用途与边界

本矩阵连接 **能力 → 可操作练习 → 前置知识 → 验收证据 → 模型缺口 → 综合应用**，用于检查内容覆盖、选择学习路径和安排实现。覆盖从需求澄清到系统演进的主要学习面，不要求首版完成全部内容，也不以收录每个算法或厂商产品为目标。

一行是一个能力单元，可以拆成多个短实验。例如 ACID、Raft、MVCC 与恢复必须分步学习；同一机制可以出现在多个案例中。能力 ID 用于关联内容，不代表新的组件类型、代码包或独立 Markdown spec。

平台始终使用有界的学习模型：可以按具体题目实现键分配、消息传递、事务调度与故障恢复规则，但不部署真实服务、数据库、消息系统或云资源。仿真组件的实际执行范围以[模型说明](../model-assumptions.md)为准，独立算法题以对应的版本合同为准；组件是否存在与练习是否可验证分别判断，见[组件覆盖](../component-coverage.md)。

## 如何读矩阵

| 项目 | 含义 |
|---|---|
| 机制 | 操作一个算法或状态模型，预测并观察结果；可用分布图、消息时间线、数据表或单步调度 |
| 模式 | 组合机制解决局部问题，例如缓存读路径、可靠事件发布、混合 Fan-out |
| 设计 | 从需求选择接口、数据组织和拓扑，提交假设、方案与取舍 |
| 诊断 | 根据有限证据定位问题，选择下一次实验，验证修复或迁移 |
| 前置 | 建议掌握的知识 ID，可由讲解或已有经验满足；不是必须先实现的产品依赖，也不强制锁题 |
| 现成 | 当前模型足以支持该行限定的实验；仍需编写题目、交互与判据，除非另标“已上线” |
| 部分 | 有可复用输入或证据，但关键语义尚缺；补齐前只能发布明确缩小范围的题目 |
| 新建 | 需要新的小型算法或状态模型；不意味着实现生产组件 |
| 设计评审 | 主要检查需求、合同与理由，使用明确评审标准；不以动画或单一数值自动判定答案 |

“当前基础”是候选练习的可行性盘点，不能替代当前模型文档。证据列描述应交付的验证能力，未上线行不表示这些证据现在已经存在。

基础知识入口 `/learn` 已提供九组 24 篇讲解、三条阅读路径及与现有 18 个 Lab 的双向关联，见[内容目录](../../apps/web/src/features/learning/catalog.ts)。讲解覆盖与可运行实验分别计数；基础实验计划已落地，各能力单元仍只覆盖明确声明的子目标。

## 统一验收与维护规则

1. **先定义问题与保证。** 记录目标能力、前置知识、初始条件、允许操作、固定约束、单位/窗口、成功条件和未覆盖语义。用学习问题命名实验，数值阈值在可复现基线中校准后固定版本。
2. **结果必须来自所声明的规则。** 参数改变应通过模型影响状态/事件/指标；示意动画单独标注，不得作为运行证据。字段若只描述、不执行，其相关保证不能判为已验证。
3. **同时验收正确路径与反例。** 每题至少有正常情形和一个能暴露误解的变更/故障；能比较方案的题目应验证多个可行解。不能靠删除业务路径、降低需求、丢弃请求或改变分母获得通过。
4. **区分证据种类。** 容量题检查守恒、队列、资源与延迟；算法题用独立小规模参考计算；协议/事务题检查状态、历史和不变量；设计题按明确标准检查需求、合同与理由，允许多解和未决项。
5. **说明证明范围。** 有限历史可以找到反例或在声明边界内通过检查，不证明任意规模、所有故障或无限执行正确。安全性与进展分开；最终收敛须声明停止新写、恢复通信、修复及冲突处理假设。原子性、隔离、线性一致性与持久性分别表述。
6. **缺证据时不给通过结论。** 保存输入、模型/题目版本、种子、故障和手动调度；截断、取消、未知语义或不匹配快照标为证据不足。失败和未完成不能被静默排除，修改后旧评分失效。
7. **诊断和比较必须能复查。** 说明改变了哪个条件、依据哪些事件作结论；相同实验条件才能用于配置对照，改变负载/故障时标明新条件。对自然语言理由可给评审反馈，但不能让无证据的自动评分覆盖模型事实。
8. **每次只交付明确切片。** 新领域模型有独立不变量/反例检查，能被第二个独立场景复用；UI 验证实际操作、证据展示、保存恢复与各题隔离。实现改动按范围测试并通过项目规定检查；文档变更运行内容与链接检查。
9. **更新状态必须有依据。** 上线后记录实际题目 ID、版本、代码/测试入口及覆盖子目标。移动或拆分能力时保留 ID 关联，并更新前置、案例和学习路径；没有题目与验收证据的行保持候选。
