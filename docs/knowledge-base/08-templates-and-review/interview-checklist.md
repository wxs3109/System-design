#Interview Checklist

## Starting stage

- [ ] Clarify users, functionality, scale and scope
- [ ] Identify the most important non-functional requirements
- [ ] Write down estimation assumptions

## Design stage

- [ ] gives the API and core data model
- [ ] Draw high-level architecture and key data flows
- [ ] Select one or two key sections to drill down into
- [ ] explains replication, sharding, caching and asynchronization choices

## Closing stage

- [ ] discusses faults, consistency, safety and observability
- [ ] Point out bottlenecks and major trade-offs
- [ ] Explain how to evolve at ten times the scale
- [ ] Summarize whether the design meets the original requirements
